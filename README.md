# 運算思維互動練習

校園資訊課用的純前端練習，結構比照資安課程：總頁、互動關卡、線上測驗。

114 學年封存的資訊科技／生活科技課堂裡，作業標題是「運算思維」。參考資料是雲端資料夾「運算思維題庫」（2013–2016 國際運算思維能力測驗題庫與詳解）。那些是競賽題，本目錄**不收錄、不改寫原題原文**。

這裡的題幹、選項和詳解都是另寫的校園情境，沿用同一種說明方式：情境、四選一或操作、為什麼對、為什麼錯、對應的運算思維。

## 怎麼開

用瀏覽器直接開 `index.html`，或在這個目錄執行：

```bash
python3 -m http.server 8765
```

然後開 `http://127.0.0.1:8765/`。

| 路徑 | 內容 |
|---|---|
| `index.html` | 總頁 |
| `play/` | 12 關。完成一關才解開下一關 |
| `exam/` | 20 題。送出後計分並顯示詳解 |

進度與最高分存在這台瀏覽器的 localStorage，不上傳。
